For the examiner

Honest limitations

One encryption key

Whoever holds the server key can decrypt. Upgrade: per-user keys derived from passwords.

Free AI tier

May keep prompts. For privileged material, use a paid no-training tier or a local model.

Cookie isn't HttpOnly

Streamlit can't set HttpOnly cookies without a reverse proxy. It's SameSite=Strict, and the token stops working when the session ends.

Polling, not push

Chat, status and notifications refresh every 3 to 30 seconds instead of updating instantly.

Mock checkout

Real payments would use Stripe Checkout and a webhook.

Calendar times

Event titles are encrypted, but times are not, so free/busy can be computed. All times use the server's time zone.
